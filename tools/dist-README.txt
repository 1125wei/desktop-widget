桌面组件 DesktopWidget · 使用说明
=================================

【怎么用】
1. 双击 DesktopWidget.exe 即可，程序常驻托盘（右下角小图标），不占任务栏。
2. 组件会贴在桌面壁纸上（在桌面图标下面、被普通窗口正常遮挡）。
3. 右键托盘图标：
   · 显示组件 / 编辑模式（可拖动） / 重新挂到桌面层 / 重置位置
   · 新增组件 → 下班倒计时 / 纪念日
   · 设置… → 改文案、配色、字体、尺寸、纪念日日期等，**改完即时生效**
   · 开机自启（勾选后每次开机自动运行）
4. 拖动摆放：托盘 → 编辑模式 → 拖卡片 → 点卡片上的「完成」（或右键卡片）。

【注：组件贴在图标层之下，所以平时点不到它是正常的，一切操作走托盘菜单】

【内置组件】
· 下班倒计时：工作日/上下班时间、发薪日、距离周五、下一个节日（含农历与传统节日）、
  今天赚了多少钱（按已过工作秒数累计）；法定节假日与调休补班自动识别（2025–2026 为
  官方公布安排，之后年份按法定假日 + 你配置的工作日）
· 纪念日：事件名 + 天数 + 起始日期，支持不重复/每年/每月；背景支持纯色 / 内置月夜 / 自定义图片

【数据与配置】
· 配置文件：%APPDATA%\wei\DesktopWidget\config.json（托盘菜单可直接打开该目录）
· 日志：同目录 widget.log（排查问题时看它）

【卸载】
· 托盘 → 退出，然后删掉本文件夹即可；
· 若开过「开机自启」，退出前先在托盘里取消勾选（或手动删除注册表项
  HKCU\Software\Microsoft\Windows\CurrentVersion\Run 下的 DesktopWidget）。
